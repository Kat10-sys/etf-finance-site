# Project notes for Claude

`public/`, or `data/*-overrides/`.** It's an internal engineering log (not
linked from the site, never served — it lives outside `public/`) used to
speed up bug-hunting by recording root causes, not just symptoms. Read the
"How to maintain this" section at the top of that file before adding an
entry, and check it first when investigating a bug — the cause may already
be documented nearby in time.
